# 桌面环境状态终端系统（嵌入式项目）

## 项目简介

基于 STM32F411 的桌面环境终端：实时显示温湿度、桌面距离/久坐提醒、旋钮交互、数据持久化和串口调试。

### 硬件清单

| 类别 | 硬件 |
| --- | --- |
| 主控 | STM32F411CEU6 |
| 显示 | SSD1306 OLED |
| 环境采集 | AHT21B 温湿度传感器 |
| 距离/状态采集 | VL53L1X ToF 测距 |
| 交互 | EC11 旋转编码器 |
| 存储 | AT24C02 EEPROM |
| 调试 | USB 转串口 + 逻辑分析仪 + ST-Link/J-Link |
